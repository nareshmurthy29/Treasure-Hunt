# Treasure Island Game

An interactive, text-based adventure game implemented in Python utilizing complex control flow structures, conditional branching, and user input validation. Players navigate through a series of choices, managing risks like river crossings and hazardous environments, to successfully locate hidden treasure.

---

## 🎮 Features

* **ASCII Art Interface:** Features an engaging terminal-based visual title screen upon launch.
* **Robust Input Validation:** Implements continuous loops (`while True`) and string normalization (`.upper()`) to gracefully handle varied user input styles.
* **Complex Control Flow:** Leverages nested conditional statements (`if` / `elif` / `else`) to build a dynamic, multi-layered decision tree.
* **Immediate Termination Logic:** Uses explicit system exits to handle fail-states professionally when a "Game Over" condition is met.

---

## 🛠️ Tech Stack & Concepts Covered

* **Language:** Python 3.14
* **Control Flow:** Nested conditions, infinite loops, and break statements
* **Input Handling:** Case-insensitive string parsing and type casting (`int()`)
* **Environment:** PyCharm IDE / Virtual Environments (`venv`)
